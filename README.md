# Module 3 Urban Design Quiz

A static, beginner-friendly multiple-choice quiz for Module 3: Movement, People and Public Spaces.

## Deploy on Vercel
1. Extract this ZIP file.
2. In Vercel, choose **Add New → Project** and import a Git repository containing these files, or use Vercel's supported CLI workflow.
3. Deploy. No environment variables, email service, API key, or backend are needed.

You can also host this static `index.html` on any static website host. The quiz runs in the browser and displays the learner's score, answer review, explanations, and retry option. Scores are not emailed or uploaded anywhere.
